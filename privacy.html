隱私政策

版本 2026-10-23，尚未生效。已確認的規劃期限為分析資料 13 個月、刪除請求 30 天內處理、備份最遲 30 天清除；現有程式尚未實作自動清除，正式啟用前須完成驗收。TikTok 原生授權與同步目前未完成。

1. 我們是誰

資料處理單位為依洛嘉國際實業有限公司。工具為「依洛嘉社群洞察儀表盤」，目前供品牌內部測試；聯絡信箱為 elgbeauty99@gmail.com。

2. 目前與規劃中的資料

目前本機儀表盤讀取已授權的 Blotato 貼文成效、Blogger GA4 彙總報表、YouTube 唯讀報表，以及管理者手動匯入的 Google 商家 CSV。各來源未取得的欄位不補造。本公開說明網站不連接本機資料庫、不讀取社群權杖、不提供分析資料查詢。

TikTok 規劃在官方與帳號持有人授權後讀取：帳號識別碼、顯示名稱與頭像；經允許的公開個人檔案連結與簡介；粉絲、追蹤、總按讚及公開影片數；公開影片識別碼、標題、描述、發布時間、連結、封面連結及觀看／按讚／留言／分享總數。僅儲存實際使用且已獲授權的欄位，不因權限存在而收集所有欄位。

另保存授權範圍、存取與更新權杖、到期資訊、讀取時間及必要的錯誤紀錄，用於維持連線與排錯；社群密碼不由本工具收取。公開留言內容、留言者名單、私訊、通訊錄、訂單及付款資料不在此 TikTok 接入範圍。

3. 使用目的

核對品牌帳號、提供成效報告與內容排行、計算可比歷史快照的增減，以及處理授權、維護與資料請求。不出售資料，不用於陌生人私訊、廣告受眾建檔或模型訓練。未取得歷史粉絲快照時不回推週月增長。

4. 保存位置與存取

現階段分析快照保存在管理者電腦的 SQLite，憑證由本機環境設定讀取；Base64 只是編碼，不是加密。現階段尚無多人線上登入或自動到期刪除功能。管理者應限制電腦與備份存取。公開 GitHub 儲存庫只放服務說明、政策頁與樣式，不放環境檔、資料庫或真實報表。若未來改為雲端保存，會先說明供應商、地區與保護方式，再更新政策。

5. 第三方與跨境處理

授權與接口請求由 TikTok、Google 或 Blotato 等相應來源處理，適用各平台政策。公開政策頁若由 GitHub Pages 託管，GitHub 會為安全目的記錄訪客 IP；詳 GitHub 隱私聲明。平台處理可能跨境；本草稿不宣稱資料只留臺灣。未來新增雲端業者或處理用途將先更新說明。

6. 保存期限與刪除規劃

正式版規劃：分析資料從擷取日起保存最長 13 個月；權杖只保留於連線所需期間，撤回或中止後停止更新並移除失效憑證。刪除請求經確認身分及範圍後，在收到請求後 30 天內完成處理或說明無法完成的原因；備份中的對應資料最遲在主資料刪除後 30 天內清除。若因適用法律必須保留，另說明必要範圍、理由及期限。

上述為使用者已確認的實作目標，尚未上線；現有本機快照不會自動清除。正式啟用前須完成主資料、備份、匯出檔與憑證刪除流程及驗收，不得直接對外宣稱已具備。

7. 撤回與資料請求

可在 TikTok 等來源平台撤銷本應用授權，並寄信至聯絡信箱申請查閱、更正、停止使用或刪除。請提供帳號公開連結與請求範圍，不寄送密碼或權杖。我們只要求核對處理權限所必要的資訊。撤銷授權本身不會自動刪除既有快照；主資料、匯出及備份須依刪除流程另行處理。刪除不影響平台原始貼文與平台自行持有的資料。

8. Cookie 與外部連結

此靜態說明網站未加入廣告追蹤、GA4 或社群登入程式。造訪 GitHub 或外部平台連結時，由該平台依其政策處理資料；本網站不將本機分析資料傳給外部連結。

9. 更新與事件處理

發現未授權存取時，管理者應停止相關連線、撤銷受影響憑證、檢查保存與備份範圍，並依適用要求通知。實際處理用途、保存地點或範圍改變時，將更新政策版本，正式政策另標示生效日期。
